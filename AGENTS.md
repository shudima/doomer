# Project workflows

When the user says **"reel it"** and supplies a video URL, article/blog URL, or PDF, read and follow [the reel-it skill](.agents/skills/reel-it/SKILL.md). In this project, **dooms** means **reels**. Store generated source collections in `/workspace/doomer/dooms/`.

After validating each new collection, commit and push its complete contents following the reel-it skill. This is part of the reel-it request unless the user asks for a local-only run.
