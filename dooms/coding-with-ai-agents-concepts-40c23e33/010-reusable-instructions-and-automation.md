Skills add reusable project knowledge and procedures to an agent’s work. The presenter describes them as Markdown instructions that supply relevant context about a codebase or project.

Automation adds another layer: scheduled jobs or events can initiate work. A submitted website form, for example, can trigger a process. Together, these capabilities let a team define repeatable work beyond a single chat exchange.
