Tell the agent what done means before asking it to implement a feature. Describe the behavior, constraints and checks that would show success.

A clear brief helps the agent make decisions and gives you a way to assess its output. The video places this work alongside planning, coding and review: the developer still directs the result, even when the agent performs much of the implementation.
