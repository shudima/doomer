The video points to a practical model of inference: model weights occupy GPU memory, while a key-value cache is generated and stored as requests are processed.

Developers do not have to treat the agent as a mystery box. Understanding basic model behavior and the resources behind it can help them use AI systems more effectively and reason about the limits they encounter.
