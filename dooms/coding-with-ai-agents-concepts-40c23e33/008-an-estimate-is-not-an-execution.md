An estimate of what should happen is different from evidence that it happened. Ask the agent to run the relevant operation and inspect its output.

For a code change, that might mean a test result, a built artifact or the app’s observed behavior. The video stresses closing the loop with execution. A convincing explanation alone cannot show that the implementation works.
