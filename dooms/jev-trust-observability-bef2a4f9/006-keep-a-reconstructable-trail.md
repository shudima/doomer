Keep enough evidence to reconstruct what happened. Record the input, relevant state, model decision, tool calls and resulting actions.

The discussion stresses this need when a system returns decisions without a long written explanation. A readable answer alone is not an audit trail. You need to inspect which information reached the model and what the system actually did with its output.
