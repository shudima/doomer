Suppose a security alert arrives and Jev recommends containing a host with 97% confidence. The security engineer still needs to know what supports that response.

Did a process match known malware? Was an IP address malicious? Was behavior unusual, or was the machine especially sensitive? An authorization misunderstanding could also matter. The same action can look reasonable for very different underlying reasons.
