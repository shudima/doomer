Some reviewed systems start with a conventional search engine, break long documents into passages and use relevant evidence to generate candidate answers. **Retrieval** need not begin with a custom-trained dense index.

Yan also describes code generation improved by a relevant code example. The retrieved material can supply implementation context the generator lacks, showing that the pattern extends beyond factual question answering.
