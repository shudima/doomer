**Illustrative example**

An uncertain newsletter classification can go into a review folder. An uncertain instruction to delete customer data should stop for stronger checks.

The same probability does not imply the same action. Define the cost of a mistake and the available recovery path before choosing a threshold or deciding when a person must review the result.
