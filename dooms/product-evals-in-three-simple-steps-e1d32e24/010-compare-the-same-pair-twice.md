**Illustrative example**

First show a judge answer A followed by answer B. Then show B followed by A.

If the same underlying answer wins both times, the result is more consistent. If the preferred answer changes with the slot, record that uncertainty instead of treating the first verdict as dependable. The example uses the article’s order-swapping method.
