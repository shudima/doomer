Tool search loads definitions, skills load procedures, and sandboxed code can filter API results before they reach context.

The survey cites one Anthropic workflow falling from about 150,000 tokens to 2,000 through code execution; this is not a universal saving. MCP standardises connections, not tool quality. Balance selective loading with cache stability, and preserve policy checks around side effects.
