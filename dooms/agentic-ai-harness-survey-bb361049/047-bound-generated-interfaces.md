Controlled generative UI selects and fills approved components. Declarative UI composes layouts from an approved catalogue. Open-ended generation supplies interface code that needs sandboxing.

Start with components the product team can test for accessibility and consistency. Allow richer composition where useful. Flexibility does not transfer responsibility: the host still owns rendering boundaries, interaction safety and a usable experience.
