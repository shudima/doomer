A prompt edit, tool description or model setting can change production behaviour as much as code. Package prompts, tools, skills, models, parameters and policies as one immutable release.

Run fast checks and a small evaluation subset on proposed changes, then full relevant suites before release. Gate quality, safety, cost and **latency** against the current version with repeated runs and statistical thresholds. Prompt and token-cost gates can reveal bloat before it reaches users.
