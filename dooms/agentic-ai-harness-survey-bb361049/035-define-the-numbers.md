Business terms such as time to hire need explicit definitions: dates, exclusions and permitted records. A plausible SQL query can otherwise return a plausible wrong number.

Enforce user **scope** in the database, expose approved views, cap query time and rows, and log queries. Show definitions or queries behind numbers. Evaluate verified result sets, not SQL text, and check consistency across differently phrased questions.
