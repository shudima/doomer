Decide which responsibilities need judgment and which need a guaranteed rule. Ask:

1. Can you specify the correct behavior in advance?
2. Could a mistake be costly or hard to undo?
3. Does the work require interpreting messy language?
4. Must the rule survive an attempt to manipulate the model?

Use code for exact rules, the model for interpretation, and code or human approval around consequential actions.
