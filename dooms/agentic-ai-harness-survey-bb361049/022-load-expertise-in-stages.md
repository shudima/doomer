A skill is a reusable procedure with optional scripts and references. Load its detail in stages:

1. Keep its name and short description available.
2. Read the instructions when the task matches.
3. Load supporting files only when the procedure needs them.

This keeps unrelated expertise out of each model call. Put exact calculations and fragile transformations in scripts that can run and be checked.
