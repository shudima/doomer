Choose how much freedom a database tool needs:

- **Reviewed queries:** common questions with controlled parameters.
- **A semantic layer:** flexible analysis using shared metric definitions.
- **Free-form SQL:** expert exploration under strong limits.

More freedom adds control problems. Keep permissions and required filters in the tool or database. Use checked business-operation tools for writes, rather than allowing arbitrary model-generated SQL changes.
