Long-term memory can save a user from repeating preferences, but wrong or stale facts can shape future decisions for months.

Start with a small user profile or editable memory files. Store provenance, dates and user-and-tenant **scope** with each entry. Let users inspect, correct and delete memories. Update contradictions and expire or reconfirm old facts. Untrusted documents should not silently plant persistent instructions; memory writes need a deliberate, reviewable path.
