An autoregressive language model writes a response one token at a time. That sequence adds time until the response is complete.

Asking it to output JSON does not remove the generation process. Caleb contrasts this with Jev’s design for parallel sampling and typed probabilistic decisions. His point is about choosing an architecture for the workload: an automation decision may need a small structured result rather than a long written answer.
