Chat products push models toward being helpful conversational partners. Coding agents push them toward implementing and debugging software. Caleb argues that demands from the application layer influence what the underlying models optimize for.

Workflow automation has a different pressure: many bounded decisions must happen quickly and affordably. A model can be very capable while still being an awkward fit for that operating constraint.
