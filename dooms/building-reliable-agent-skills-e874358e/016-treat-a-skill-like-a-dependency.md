Before using a skill from someone else, read what it does and check the systems or destinations it reaches. The presenters compare that review to checking a package before adding it to a project.

An open standard describes the format. It does not certify that a specific package of instructions and scripts is safe. The review has to follow the actual behavior inside the folder.
