Keep the skill’s entry point short. Give the agent enough information to recognize the job and find the next instruction.

Move detailed references into separate files and load them when needed. This is **progressive disclosure**: reveal detail as the task calls for it. The video recommends spending the limited context window on the current work rather than loading every possible instruction at once.
