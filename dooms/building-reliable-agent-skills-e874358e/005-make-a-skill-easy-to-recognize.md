**Illustrative example**

A skill named “Helper” gives little clue about when to load it. “Prepare monthly invoices from approved time entries” describes an actual job.

Its description can mention both the input and the trigger. That helps the agent select the procedure for invoice work while avoiding it for an unrelated request to summarize a meeting.
