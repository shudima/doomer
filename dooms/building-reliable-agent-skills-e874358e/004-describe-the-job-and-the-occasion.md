A description such as generating reports is too vague. The video’s stronger example identifies a monthly compliance report from internal data and says to use it for requests about that report or the monthly filing.

State both what the skill does and when it applies. The presenters also warn about under-triggering: a skill can be well written and still accomplish nothing if the agent fails to select it.
