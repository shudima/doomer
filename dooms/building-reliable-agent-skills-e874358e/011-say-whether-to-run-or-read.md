A script can serve as reference material or as an operation the agent must execute. The skill should state which role it has.

The presenters emphasize explicit intent: tell the agent to run a script when execution is required, and identify material that should only be read. Clear directions prevent the procedure from depending on the model guessing what the file was meant to do.
