A large skill can move supporting material into a references directory. The agent reads those files when the task needs their detail, instead of loading everything with the main instructions.

The video calls this **progressive disclosure**. It lets a procedure remain thorough while keeping its active instructions lean. The key is to make extra information available at the point where it is useful.
