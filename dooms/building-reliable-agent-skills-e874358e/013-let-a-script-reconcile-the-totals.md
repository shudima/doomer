**Illustrative example**

A reporting skill needs line items, tax and a final total. Let a script calculate those values from the source rows.

The agent can explain unusual entries and write the summary. Then compare the displayed total with the script’s result. This keeps exact arithmetic in a checkable step while leaving interpretation to the model.
