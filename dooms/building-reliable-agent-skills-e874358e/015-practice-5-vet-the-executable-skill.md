A skill’s scripts may reach local files or API keys. The video cites an audit of nearly 4,000 public skills that reportedly found security flaws in over 35%, with critical issues in 13%.

Those are the presenters’ cited figures, not a guarantee about any particular skill. Their practical point is to review the code and its access before allowing an unfamiliar procedure to run.
