One model that sees the results of earlier steps can connect them directly instead of relying on summaries passed between specialists. That can improve continuity and reduce lossy handoffs.

Skills and tool search let the agent load relevant procedures and schemas on demand, keeping the shared window from becoming a dump of every team’s knowledge. The benefit depends on disciplined context management, not simply deleting the orchestrator.
