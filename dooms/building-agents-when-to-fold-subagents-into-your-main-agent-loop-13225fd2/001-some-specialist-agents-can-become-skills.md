Some specialist agents mainly contribute instructions and a toolset. Their work may fit inside the main agent as a **skill**.

Anthropic describes replacing some of these boundaries with instructions loaded when needed. The main agent can then keep the relevant context while following the specialist procedure. Separate agents still help when they provide useful isolation, parallel work or a genuinely different context.
