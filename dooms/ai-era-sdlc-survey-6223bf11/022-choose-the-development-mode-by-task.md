The survey distinguishes three modes. Inline assistance offers completions while an engineer works in familiar code. Interactive agents plan, edit files and run tests while the engineer steers. Background agents work asynchronously from a scoped issue toward a draft pull request.

Use the mode that fits the uncertainty and feedback needed. Well-specified chores and migrations suit delegation. Features, debugging and refactoring often benefit from interaction. One engineer can move between modes as the task becomes clearer.
