HealthBench Pro applies the same 2,000-character target across different clinical uses. Yet physicians’ baseline responses range from about 600 to 3,800 characters between the 10th and 90th percentiles.

A short consult and a full documentation task can need different amounts of explanation. Yan suggests comparing length with the physician’s response for that task. This is a proposal for fairer adjustment, alongside the content-based checks.
