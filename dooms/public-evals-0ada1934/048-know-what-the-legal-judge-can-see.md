Harvey LAB runs models in an offline sandbox with read-only matter files, six file and shell tools, and document-production skills. The run has a 200-turn limit.

Its model judge sees the task title, deliverables, and one rubric criterion at a time. It does not receive the underlying matter files or reference answers. Every criterion must pass. This visibility boundary shapes which mistakes the judge can detect.
