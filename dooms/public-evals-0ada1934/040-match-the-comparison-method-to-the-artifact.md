ALE uses different checks for different outputs. Workbooks can use field tolerances. Code can use held-out tests. A 3D model can be compared with a reference surface.

About 93% of grading is deterministic. Narrow yes-or-no model judgments cover some creative or perceptual outputs. ALE reports both mean partial score and full-pass rate, so readers can see progress and complete delivery separately.
