ALE prioritizes outputs that can be compared with a target. A task might list exact filenames, labels, or every required animation bone. Some open-ended work becomes reproduction.

Yan also observes that about half the public tasks involve scientific or research computing. These can be demanding tasks, while still testing a narrower mix of skills than the broad industry-work description suggests. Read the actual requests to understand that mix.
