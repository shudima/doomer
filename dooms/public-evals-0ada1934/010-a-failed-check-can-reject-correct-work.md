A **false negative** occurs when valid work receives a failing grade. The check may enforce an unstated requirement, expect one particular implementation, or use a bad answer key.

Yan’s review gives examples across coding, browsing, and desktop tasks. When several capable agents fail the same assertion, inspect the assertion and the prompt together. A shared failure can reveal a defect in the evaluation.
