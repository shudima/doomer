Terminal Bench can retire tasks once strong models solve them reliably. That keeps the benchmark challenging, but a score from a newer release may face a different task mix.

Yan suggests a companion result on a fixed subset. The changing set helps separate frontier systems. The fixed set helps readers see how performance changes over time against the same work. Report both with their version information.
