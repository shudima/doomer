Agents’ Last Exam, or ALE, began with 1,490 tasks drawn from substantial professional projects. Its public v1.1 set contains 122 tasks after retiring 30 from the original public set.

Agents work for up to five hours in Ubuntu or Windows environments with professional software and input files. The benchmark lets the submitted harness bring its own tools and memory. That makes the complete agent setup part of the result.
