A model can retrieve prior work more reliably when code, project notes and domain knowledge have predictable locations. Yan separates software projects from a structured knowledge vault.

The important property is discoverability. A clear directory tree lets the assistant search for relevant evidence and reuse existing artifacts instead of reconstructing the project from scratch in every conversation.
