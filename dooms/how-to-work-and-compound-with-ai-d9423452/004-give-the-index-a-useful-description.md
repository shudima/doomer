**Illustrative example**

An index entry named `notes-7.md` gives the assistant little help. “Deployment guide: Render settings, health checks and rollback steps” explains when the file matters.

Keep the description short and the link current. The next session can choose the relevant reference before reading every file, leaving more attention for the actual task.
