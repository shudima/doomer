A new model session lacks the working memory of the previous conversation. Yan treats project instructions as a new teammate's onboarding document.

Glossaries clarify abbreviations, project names and people with similar names. A suggested reading order points the assistant toward the index, current tasks and relevant notes. This makes local context explicit rather than assuming the assistant already shares it.
