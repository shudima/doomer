Make today’s AI session easier to build on tomorrow. Save useful context, repeated procedures and corrections where the next session can find them.

Eugene Yan calls this compounding with AI. The benefit comes from improving the working system over time: a better index, a clearer rule, a reusable skill or a check that catches the same mistake next time.
