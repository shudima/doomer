Existing APIs can become useful agent tools without every team rebuilding discovery, access control and execution infrastructure.

Uber’s takeaway is to share those capabilities through a gateway and registry. Teams can reuse a controlled path to their services while improving tool descriptions and contracts for agents. The common protocol helps connect the pieces; the quality of the surrounding system makes them usable.
