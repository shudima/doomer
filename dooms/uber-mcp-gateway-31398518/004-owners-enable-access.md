Finding a tool does not grant permission to use it. Uber starts discovered tools in a disabled state.

Owners review the definition and decide when to enable access. They also approve versioned changes and can roll back. This gives a tool’s maintainers a clear control point instead of turning every automatically discovered endpoint into an immediately available agent capability.
