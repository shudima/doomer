**Illustrative example**

A meeting-preparation skill explains how to find recent customer calls. Reading that skill also makes the call-search tool available.

An unrelated writing task needs neither the tool definition nor the instructions. Binding them keeps the procedure executable while limiting how much material every task must carry.
