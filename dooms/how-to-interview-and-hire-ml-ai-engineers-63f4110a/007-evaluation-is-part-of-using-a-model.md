Even an engineer using an off-the-shelf model should know how its performance was assessed. Yan asks about initial evaluation data, the harness, monitoring after updates and responses when metrics crossed important thresholds.

The principle is empirical responsibility. Selecting a capable model does not remove the need to determine whether the actual product continues to behave acceptably over time.
