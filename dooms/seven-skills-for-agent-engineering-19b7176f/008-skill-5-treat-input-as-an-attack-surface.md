**Prompt injection** uses malicious instructions inside input to steer an agent away from its intended task. The video illustrates an attacker trying to override instructions and obtain user data.

This is a security problem created by a system that interprets information and can act on it. Builders need to consider how hostile material could influence the model, rather than assuming that a carefully written prompt ends the threat.
