The seven-skill stack can look daunting, but the video suggests a concrete first improvement: read a tool schema as though a new engineer had to use it.

Would that person understand exactly what the tool does and expects? If not, tighten the contract with strict types and examples. This gives an existing agent a more dependable interface without requiring a complete redesign of the system.
