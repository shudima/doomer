Choose one failure that keeps recurring and investigate the path to it. Was the right document retrieved? Was the appropriate tool selected? Was its schema clear?

The presenter recommends doing that before rewriting the prompt again. One schema cleanup and one traced failure turn the broader skill stack into practical work. Agent engineering advances by improving the system that produces the result, not merely polishing its instructions.
