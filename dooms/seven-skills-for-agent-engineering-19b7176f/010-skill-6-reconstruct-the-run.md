When an agent fails, debugging needs a timeline. Which tool did it call, with which parameters? What did **retrieval** return, and what decisions followed?

The video calls for tracing the run so investigators have evidence beyond the final answer. Recording available actions, inputs and outputs makes it possible to follow a failure through the system instead of guessing which sentence in the prompt caused it.
