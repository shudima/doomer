Does the agent need database write access? Should it send email without approval? What happens when it misunderstands a request and attempts something dangerous?

The presenter pairs those questions with input validation, output filters and permission boundaries. Security includes controlling which actions are available in the first place. The threat model changes with agents, but the discipline of limiting access and checking behavior remains familiar.
