Keep working memory separate from confirmed customer facts. A question about Florida may suggest that a move matters, but it does not establish a new address or plan.

The article uses selected graph nodes and indexed passages to keep relevant context small. It treats a possible move as memory until confirmed enrollment supplies stronger evidence. Remembering a conversation should not silently overwrite an authoritative record.
