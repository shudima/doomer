A sales-analysis agent may query a database, calculate results, prepare a report and craft a response. Multiple agents make that coordination more involved.

An agent framework provides building blocks for such systems. The video emphasizes the planning, actions and iteration that sit around a model, rather than treating an agent as a chatbot that only receives a question and returns an answer.
