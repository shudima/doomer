**Illustrative example**

For a research brief, a researcher collects evidence, a writer explains it and an editor checks clarity.

Give each role a distinct result and decide who owns the final brief. If all three agents repeatedly rewrite the same paragraph, the boundaries are adding coordination without much benefit. Use the roles only when their separate work improves the outcome.
