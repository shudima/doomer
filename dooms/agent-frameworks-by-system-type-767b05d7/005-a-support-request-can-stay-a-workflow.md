**Illustrative example**

A support system must look up an order, check its delivery state and draft an answer. The sequence is known.

Write those steps as a workflow and use a model only where language interpretation helps. If the order lookup fails, handle that branch explicitly. You can test each step without asking a group of agents to rediscover the same plan.
