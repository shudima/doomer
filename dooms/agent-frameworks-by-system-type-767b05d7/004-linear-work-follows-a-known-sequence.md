For a customer-support request, a system can search a knowledge base, draft a response and create a support ticket. The steps follow a reasonably predictable order.

The video recommends a workflow approach when that order and control matter. Several collaborating agents are not necessary just to make the sequence happen. A simpler progression can make it clearer what the application should do next.
