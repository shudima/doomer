Memory can drift as the environment changes, and checking every note repeatedly costs compute. Anthropic suggests focusing background work on information likely to change or choosing a cadence based on which notes are used.

Searchable transcripts can serve as a foundation. Add notes, a wiki, or startup context where they help future work enough to justify keeping them accurate. Dreaming gives the agent a chance to make that memory easier to use as experience accumulates.
