During a task, an agent can record events and write quick notes. Between tasks, it can review those records, correct mistakes, and organize what future sessions should see. The article calls that background pass **dreaming**, drawing on sleep-time compute research from Letta and UC Berkeley.

The analogy is how human memory can capture experiences quickly and consolidate some of them later. For an agent, the work happens over explicit logs and files.
