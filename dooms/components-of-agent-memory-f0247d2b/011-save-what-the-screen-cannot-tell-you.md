A Pokémon player can see its current money and location on the screen. Saving a copy creates another value to keep up to date. At one point Sonnet 3.7 spent 17 steps reorganizing memory and took no game actions.

Fable 5 used `global.md` as a dashboard for the current goal and plan. It kept route plans and gameplay strategies in separate folders. Opus 5.5 similarly maintained a small set of notes as it played and finished the game.
