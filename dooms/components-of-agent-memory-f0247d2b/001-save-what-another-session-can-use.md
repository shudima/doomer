Agent memory is knowledge picked up during work and saved somewhere a later session can read it. It can carry a user preference, a tested rule, or the next step in a task across a fresh start.

+**Illustrative example.** A coding assistant learns which test command the team uses and leaves a note with the working command. The next session can read that note. A conversation summary serves a different purpose when it replaces earlier turns so the current task can continue.
