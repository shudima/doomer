Raschka’s log inspection suggests Claude Code’s extra usage came mainly from input tokens. The harness repeatedly supplied accumulated conversation, tool calls, command output, and file contents; it was not simply generating twice as much code.

One example used about 578,000 input tokens and 4,500 output tokens across 25 turns. This is the article’s likely explanation for those runs, rather than a controlled demonstration that one mechanism accounts for every token difference.
