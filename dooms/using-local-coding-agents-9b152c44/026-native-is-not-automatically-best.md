When Raschka reran his small agent assessment with Codex, Qwen3.6 performed better than it had in Qwen Code. That surprised him because the model was expected to fit its own harness well.

The result makes Codex worth testing as a common interface for multiple models. It does not establish that Codex wins every task: this was a tiny benchmark, and different projects may exercise different tool behavior, context handling, or recovery strategies.
