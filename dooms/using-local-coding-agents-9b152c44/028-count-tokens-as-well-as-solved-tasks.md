In the article’s agent tests, Claude Code used the most tokens on average and Codex the fewest. Qwen and North Mini Code solved all five tasks through Claude Code, showing that extra harness work can accompany strong results.

Raschka’s broader observation is that token usage depends heavily on the harness, not just the model. Compare successful runs on the same tasks before deciding whether a model or an interface feels inherently slow.
