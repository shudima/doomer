Raschka prefers testing agents on a separate machine such as his DGX Spark. A virtual machine or separate operating-system account offers another practical boundary for a harness that can read and edit local files.

For a modest spare computer, he also describes using a local harness with a stronger cloud-hosted open-weight model. That can reduce hardware requirements, but it introduces hosting costs and sends model requests beyond the local machine.
