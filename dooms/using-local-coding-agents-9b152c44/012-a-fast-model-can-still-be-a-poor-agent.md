Gemma 4 E2B’s failures in the small reasoning test were not merely cosmetic JSON problems. It selected the wrong tools and requested clarification when the supplied context was sufficient.

Raschka would reserve it for narrow, heavily constrained coding tasks. For Qwen’s imperfect results, he suggests that stronger project context, constrained actions, and retries could help. Those are possible harness improvements, not evidence that the underlying model already makes reliable decisions.
