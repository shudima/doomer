**Illustrative example**

Use the same repository snapshot and bug report for two local coding setups. Record whether each fixes the bug, passes the checks, respects scope and finishes within your budget.

A faster token rate can still lead to a slower or incorrect task. Compare the model, runtime and harness as a working combination.
