If two harnesses solve the same tasks, substantially lower token use can be a major efficiency advantage. Raschka gives Codex’s roughly 50% token saving over Claude Code as an example and argues that this can make work much faster.

But task success alone does not assess code readability or quality. Nor does a token count by itself guarantee a particular wall-clock speedup: prompt processing, generation, and tool execution contribute differently to the time a user waits.
