An evaluation task and an attempt are different objects. The task defines the starting conditions and what success means. An attempt is one run of the system on that task.

Keep the result and trace for each attempt. This makes repeated trials comparable and helps separate an easy task from a lucky run. The survey recommends explicit evaluation structure rather than treating every transcript as a new test case.
