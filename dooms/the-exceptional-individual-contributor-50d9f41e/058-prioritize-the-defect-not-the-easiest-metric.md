In a composite helpdesk example, trace review reveals repeated questions, wrong tool use and outdated guidance. The team builds a narrow model judge for the first, a direct tool check for the second and a knowledge-source fix with a regression test for the third.

Verbosity is deferred as less important. The example illustrates matching intervention and evaluation to the observed failure rather than giving every category the same generic score.
