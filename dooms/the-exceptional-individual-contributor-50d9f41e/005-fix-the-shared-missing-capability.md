In the survey's composite example, three assistant teams maintain separate **retrieval** systems but cannot tell whether model changes improve quality. Rewriting one pipeline would help only one team.

The principal instead proves a shared evaluation harness with one team and helps the others adopt it. The example illustrates greater organizational leverage despite producing less personal implementation output than before.
