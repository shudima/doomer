The survey argues that coding agents amplify engineering expertise. Clear specifications, decomposition, tests and critical review become more important when producing implementation is easier.

The engineer still owns design and correctness. Agents can expand exploration and prototype options, but accepting plausible code without understanding it merely moves work into later maintenance, integration and incident response.
