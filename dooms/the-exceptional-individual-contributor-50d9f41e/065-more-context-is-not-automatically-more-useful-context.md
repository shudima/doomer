Keep the context needed for the next decision. More material can make the right detail harder to find.

The survey recommends a small, relevant working context with references to deeper evidence. Retrieve detail when needed and preserve task state across summaries. When a run fails, inspect what the model actually saw before assuming that it needed a larger context window.
