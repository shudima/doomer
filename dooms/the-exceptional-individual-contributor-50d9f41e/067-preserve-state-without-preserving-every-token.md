Compaction summarizes older history so a task can continue within context limits. External notes preserve important state for later **retrieval**. Focused subagents can investigate in separate contexts and return condensed findings.

The survey presents these as complementary approaches. Their value depends on preserving the user's constraints and useful evidence, rather than merely reducing token count while losing the information needed to finish correctly.
