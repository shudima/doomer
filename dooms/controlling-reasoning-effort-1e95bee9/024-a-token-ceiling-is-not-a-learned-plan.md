**Illustrative example**

A hard limit ends generation after a fixed number of tokens. A budget-aware model is trained to use the available effort productively.

Imagine a student whose exam is cut off after one page versus a student told to plan a one-page solution. Both have a limit, but only the second has an opportunity to adapt the approach to it.
