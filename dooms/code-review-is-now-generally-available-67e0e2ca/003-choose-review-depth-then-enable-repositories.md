Administrators can choose **Quick, Standard or Deep** review for each repository. Standard is the default. The announcement presents this as a way to match review depth to the codebase.

An administrator enables Code Review in Claude Code settings, installs the GitHub App and selects repositories. According to the announcement, developers then receive automatic reviews on new pull requests without adding their own configuration.
