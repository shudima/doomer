**Illustrative example**

The project originally used SQLite. It now uses PostgreSQL, but both setup notes remain in context.

Update the maintained guide and mark the old note as obsolete. Give the agent the current connection instructions. A fresh “use PostgreSQL” sentence buried beneath the old guide leaves unnecessary ambiguity about which version to follow.
