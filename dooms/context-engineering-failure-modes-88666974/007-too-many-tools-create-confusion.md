A migration agent might have version control, a database console and a ticketing system available. Their tool definitions remain in context even when the agent does not use them.

The presenter cites a benchmark where a model failed with 46 tools but passed the same task with 19. The example illustrates context confusion: extra capabilities can make selecting the appropriate tool harder.
