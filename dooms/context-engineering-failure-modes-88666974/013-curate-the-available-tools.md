The proposed fix for context confusion is curation. A database migration does not need every tool the surrounding platform can offer.

Start with the handful the job calls for, and allow the agent to obtain others if the work actually needs them. That reduces the selection burden created by unused definitions while keeping a path to additional capabilities when they become relevant.
