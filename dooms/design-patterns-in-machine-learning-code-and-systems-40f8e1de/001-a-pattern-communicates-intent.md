A design pattern gives a common name to a recurring solution. It helps another developer understand why a component exists and how to use it.

Eugene Yan illustrates patterns in machine-learning libraries and systems. The names are useful when they clarify a design: a factory creates something, a strategy swaps an algorithm, and a mediator coordinates components. Naming a pattern is a way to explain intent.
