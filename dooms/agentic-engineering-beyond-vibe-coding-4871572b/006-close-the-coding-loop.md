**Illustrative example**

Ask an agent to fix a search filter. A useful loop is: reproduce the bug, change the filter, run the relevant check and inspect the interface.

A generated patch alone leaves the outcome uncertain. The feedback from execution gives the agent a chance to correct the patch and gives you evidence that the intended behavior changed.
