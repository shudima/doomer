Start with a small task whose outcome you can check. Watch where the agent gets stuck, takes the wrong action or produces a convincing mistake.

Improve the instructions, tools or feedback that caused that failure, then try again. The video recommends learning from this loop before granting broader autonomy. A bounded task makes both progress and mistakes easier to understand.
